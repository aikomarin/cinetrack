## css/utilities/text.css

`/* Utilidad: Alineación de texto */`: identifica la regla auxiliar que cambia la alineación horizontal de un bloque de texto.

---

```css
.detail-text-justified {
  text-align: justify;
}
```

`text-align: justify`: distribuye el espacio entre las palabras para que el texto quede alineado tanto en el borde izquierdo como en el derecho.

Pendiente de nomenclatura: `.detail-text-justified` incluye la palabra `detail`, aunque la clase funciona como una utilidad de alineación. No se modifica todavía porque puede tener dependencias en templates.
